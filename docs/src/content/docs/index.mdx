## Migration notes

- **Docker Deprecation**: Docker-backed execution remains active in v9 but is deprecated and planned for removal in v10. Keep existing workflows on container execution for v9.
- **Removed Inputs**: Action-level template, branding, and analytics/dashboard features are fully removed in v9. Remove these inputs from your workflow configurations.
